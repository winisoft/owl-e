three-letter tags to increase comprehensibility and maintainability.

# ICO = icon
    Reflects the existence of an image, not necessarily anything else

Icons belong to one of the following categories -- in other words, only one of
them is applicable.
    
    OEL = OElement
        A classification for a data type that is uniquely and Owl-E workflow configuration type
    
    DIR =  Directional
        Representative of directional indications

    Directional icons include: 
        CHE = Chevron
        ARW = Arrow
        ARC = Arrow Circled

    
    VRE = View Resize / Reorientation
        Representative of UI elements for repositioning UI elements
        EXP = expand
        COL = collapse
    
    TGL = Toggle
        Representative of two-state (on / off) toggleable condition
    
    DIC = Indicator
        Represents UI content representative of visual feedback
    
    NTR = Interactive
        Represents HMI content
    
    PAY = Payment methods
    
    
CND = Content Description
    Useful, for example, to screen readers

UFN = User Facing Name
    A friendly name for the fundamental concept represented
