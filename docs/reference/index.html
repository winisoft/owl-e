Owl-E Reference

Three views of one system. A model describes the shape of a record, an endpoint describes how to move one across the wire, and an error describes the rule that turns one away. Every constraint on a model links to the error it raises, and every error lists the fields that raise it.

WorkflowRequirement

A distribution a workflow's environment must provide. A released package is identified by **(distribution, version) together** — `version_id` alone does not name one, because many distributions share a version number. That is why the database enforces a compound foreign key into `packages` rather than a reference to `versions`, and why the two halves appear separately here. [requiredPackageVersion] being null is meaningful rather than missing: it says no version was pinned, so the distribution installs as-is — `pip install numpy`.
